# 民宿AI平台推广工具

一个简约的网页工具，帮助您将民宿信息快速推送到各大AI平台（豆包、千问、元宝等），让用户在AI平台搜索时能轻松找到您的民宿。

## 功能特点

✨ **极简设计** - 界面简洁明了，操作直观
🚀 **一键推广** - 同时推送到多个AI平台
📝 **内容优化** - 自动生成AI平台友好的内容格式
🎯 **SEO优化** - 包含关键词和问答格式优化
📊 **实时进度** - 查看每个平台的提交状态

## 支持的AI平台

- 豆包
- 千问（阿里）
- 元宝（腾讯）
- Kimi
- 文心一言（百度）
- 智谱清言

## 使用方法

1. **打开网页**
   - 直接在浏览器中打开 `index.html` 文件

2. **填写民宿信息**
   - 民宿名称（支持两个民宿）
   - 位置
   - 特色描述
   - 联系方式

3. **添加宣传内容**
   - 视频链接（抖音、小红书等）
   - 图片链接
   - 笔记/文章链接

4. **选择目标平台**
   - 勾选要推送的AI平台

5. **预览或提交**
   - 点击"预览内容"查看生成的推广内容
   - 点击"开始推广"提交到各平台

## 技术说明

### 当前版本
这是一个**演示版本**，展示了完整的用户界面和交互流程。实际的API提交功能需要：

1. **获取各AI平台的API密钥**
   - 需要在各平台注册开发者账号
   - 申请API访问权限

2. **配置真实的API端点**
   - 在 `script.js` 中的 `AI_PLATFORMS` 对象中配置真实的API地址
   - 根据各平台要求调整数据格式

3. **后端服务（可选）**
   - 为了安全性，建议通过后端服务器处理API密钥
   - 避免在前端暴露敏感信息

### 实际部署建议

如需实际使用，建议：

1. **联系各AI平台**
   - 了解是否有内容提交API
   - 申请商业合作或开发者权限

2. **搭建后端服务**
   ```
   前端 → 后端服务器 → AI平台API
   ```

3. **数据存储**
   - 保存提交记录
   - 定期更新内容
